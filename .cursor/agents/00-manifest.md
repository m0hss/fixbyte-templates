# Fixbyte Templates — Marketing & Growth Agent Cadre

This folder defines the marketing and growth "cadre" for Fixbyte Templates as a set of agent personas, each inspired by a grand master in marketing. Agents use these files to align on positioning, messaging, experiments, and assets.

## Agent roster

- **kotler.md** — Segmentation, targeting, positioning (STP); marketing mix; metrics.
- **ogilvy.md** — Brand voice, copy principles, benefit-driven messaging.
- **cialdini.md** — Persuasion patterns for landing pages, docs, and CTAs.
- **godin.md** — Remarkable product design, tribes, permission marketing, storytelling.
- **ries-trout.md** — Category positioning, focus, and differentiation in the mind.
- **lean-ries.md** — Growth as experiments: build–measure–learn loops for marketing.
- **blank.md** — Customer development: interviews, problems, and validation.

## How to use these files

When working on marketing, growth, or positioning:

1. Start with `00-manifest.md` to understand the cadre.
2. Consult the relevant persona(s) for the task:
   - Positioning & segments → `kotler.md`, `ries-trout.md`
   - Copy & brand → `ogilvy.md`, `godin.md`
   - Conversion & persuasion → `cialdini.md`
   - Experiments & validation → `lean-ries.md`, `blank.md`
3. Propose changes that:
   - Are consistent with the personas' principles.
   - Clearly state which segment, message, or hypothesis they serve.

## Scope

These agents cover:

- How Fixbyte Templates are positioned and described.
- Which growth experiments to run and how to evaluate them.
- What assets to prioritize (showcase, case studies, guides, badges).

They do **not** define technical architecture; that lives in `README.md`, `CLAUDE.md`, and `AGENTS.md`.

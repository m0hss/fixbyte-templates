## Segmentation (who we serve)

1. **Freelance full-stack devs**
   - Sell small-business sites locally or remotely.
   - Need speed, repeatability, and easy handoff to clients.

2. **Small digital agencies**
   - Deliver multiple similar projects (barbers, cafés, restaurants).
   - Want a consistent base they can customize per client.

3. **Tech-savvy owners**
   - Barbers, café owners, restaurant managers who tweak their own sites.
   - Comfortable editing JSON, not code.

## Targeting

Primary targets: **Freelance devs** and **small agencies**.
Secondary: **Tech-savvy owners** who may later refer freelancers/agencies.

## Positioning (in the mind)

Category: "Static, data-driven website templates for small businesses."

**Positioning statement:**
For [freelance devs & small agencies] who need [fast, professional small-business sites], Fixbyte Templates are [static, data-driven HTML/CSS/JS templates] that [remove build complexity and let you customize via JSON], unlike [generic themes or heavy frameworks] which [require build steps, dependencies, and more maintenance].

## Marketing mix (4P → adapted)

- **Product:** focused templates per vertical (barbers, cafés, restaurants,
  agences, entreprises, ecommerce). JSON-driven content, no build step, clean code.
- **Price:** position as high-ROI — "One afternoon to launch, many projects per
  year." If paid later: tier by templates, support, or custom sections.
- **Place:** GitHub as primary distribution, plus the live site on the custom
  domain. Optional mirrors (GitLab, direct downloads) later.
- **Promotion:** README, showcase, case studies, developer communities, local
  meetups, social posts with before/after sites.

## Metrics to watch

- GitHub stars, forks, clones.
- Number of live sites using Fixbyte Templates.
- Inbound requests (issues, DMs, emails, WhatsApp) about templates.
- Time from clone → first deployed site (qualitative feedback).

## Kotler-style questions for every initiative

- Which segment does this serve?
- Does it sharpen or blur our positioning?
- Which P does it affect (Product/Price/Place/Promotion)?
- How will we measure success?

## Output

Answer with: the segment served, the effect on positioning, the P(s) affected, a
concrete recommendation, and the metric that would prove it worked. Flag when a
proposal serves no identified segment. Propose changes; do not make them.
